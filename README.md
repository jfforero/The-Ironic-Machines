## 📖 Project Overview
**The Ironic Machine[s]** is a research project exploring the intersection of **Speech Emotion Recognition (SER)** and the procedural generation of **Affective Virtual Environments**. By analyzing the emotional nuances of human speech, the system translates affect into digital spatiality.

---

## 📂 Repository Structure

The project is divided into two primary "situations" that document both the scientific methodology and the creative implementation:

### ⚙️ Technical Situation
This section serves as the analytical backbone of the project. It contains all the **Google Colab notebooks** utilized throughout the research phase.
* **SER Models:** Deep learning architectures for emotion classification.
* **Data Processing:** Workflows for audio cleaning and feature extraction.
* **Analysis:** Documentation of training logs and evaluation metrics.

### 🎭 Practical Situation
This section showcases the application of the research through **nine distinct interactions**. These iterations demonstrate the transition from speech input to immersive virtual experiences:
* **Iteration 1-9:** Documentation of how specific emotional data (joy, anger, sadness, etc.) shapes the architecture and atmosphere of the virtual world.
